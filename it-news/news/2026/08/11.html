Varonis, 에이전트 의도 기반 접근 제어(IBAC) 출시…AI 에이전트 보안 새 기준 제시발행 2026년 08월 03일 (월)globenewswire.com

Varonis Systems가 8월 3일 Atlas 플랫폼에 에이전트 의도 기반 접근 제어(IBAC)를 출시해, 기업이 AI 에이전트에 기업 데이터 접근을 허용하면서도 실시간으로 행동 경계를 동적 적용할 수 있게 됐다. 전통적 역할 기반 접근 제어와 달리, Agent IBAC는 에이전트의 실시간 추론·도구 호출·데이터 접근 패턴을 선언된 지침과 비교해 '의도 이탈(intent drift)'을 감지하면 세션을 격리하고 인간 승인 게이트를 트리거하며 전체 감사 추적을 생성한다. Claude Code, Cursor, GitHub Copilot, Microsoft Copilot Studio를 즉시 지원하며 출시됐다. Varonis 주가는 발표 당일 약 8.9% 상승했고 회사는 동시에 2026년 매출 전망도 상향 조정했다.

WHY IT MATTERS

전통적 ID 접근 관리 도구는 에이전트가 선언된 범위 내에서 행동하는지 판단할 수 없다. Varonis가 '의도 인식 접근 제어'라는 새 제품 카테고리를 개척한 것은, 기업 AI 에이전트 도입이 본격화되면서 에이전트 거버넌스가 선택이 아닌 규정 준수·보안의 필수 레이어로 자리잡고 있음을 시사한다. 주가 상승과 매출 전망 상향은 시장이 이를 즉각적 예산 집행 항목으로 인식하기 시작했음을 보여준다.

AI 개인화가 통계적으로 검증된 성과를 내면서 '개인화 마케팅을 해야 한다'는 논쟁은 끝났고, 이제 '어느 수준의 개인화 AI를 얼마나 빨리 구축하느냐'의 실행 경쟁으로 이동했다. 고객 데이터 플랫폼(CDP)의 데이터 품질과 인프라 수준이 AI 마케팅 효과의 가장 강력한 결정 요인이 되면서, CDP 투자 ROI가 과거 어느 때보다 높아졌다.
