Anthropic 주도의 Model Context Protocol(MCP)이 2026년 7월 28일 다섯 번째 주요 사양을 정식 출시하며, 프로토콜 핵심부를 스테이트풀(stateful) 세션 방식에서 스테이트리스(stateless) 요청/응답 모델로 전환하는 사상 최대 규모의 개정을 단행했다. 기존에는 initialize 핸드셰이크와 세션 ID 추적이 필수였으나, 신규 사양은 이를 완전히 제거하고 클라이언트·서버 정보를 각 요청의 _meta 필드에 인라인으로 포함시켜 스티키 세션 및 Redis 등 공유 세션 저장소가 불필요해졌다. 이 변경으로 MCP 서버는 서버리스·엣지 인프라에서 일반 라운드로빈 로드 밸런서만으로 배포 가능해졌으며, TypeScript·Python 양대 Tier-1 SDK가 각각 누적 10억 건 다운로드를 돌파한 가운데 월간 전체 SDK 다운로드는 약 4억 건에 달한다. Tasks, MCP Apps, 권한 강화(Authorization Hardening), 공식 Extensions 프레임워크도 동시에 GA 전환됐고 Tier-1 SDK 4종 모두 발행일 당일 완전 지원을 선언했다.

WHY IT MATTERS

스테이트리스 전환은 AI 에이전트 인프라를 기존 웹 아키텍처와 동일한 방식으로 운영·확장할 수 있게 하는 구조적 분기점으로, 엔터프라이즈가 MCP 서버를 멀티 리전·클라우드 네이티브 방식으로 배포하는 데 드는 운영 복잡성과 비용을 대폭 낮춘다. AWS AgentCore, Claude 제품군 등 주요 플랫폼이 즉각 지원을 선언한 만큼, MCP의 사실상 업계 표준(de facto standard) 지위가 더욱 공고해질 것이며 자체 독점 프로토콜을 추진 중인 경쟁 진영의 전략 수정 압박이 커질 전망이다.

The Flexibility Trap: Rethinking the Value of Arbitrary Order in Diffusion Language Models (ICML 2026 Best Paper)발행 2026년 07월 05일 (일)icml.cc

청화대학교 LeapLab 연구팀이 ICML 2026 최우수 논문상을 수상한 이 연구에서 확산 대형 언어 모델(dLLM)이 임의 순서로 토큰을 생성하는 유연성이 강화학습(RL) 훈련 시 오히려 추론 성능을 저해하는 '유연성 함정(Flexibility Trap)'을 실험적으로 규명했다. dLLM은 RL 탐색 단계에서 높은 불확실성을 지닌 핵심 추론 분기 토큰을 우회하는 경향이 있어 솔루션 커버리지가 조기에 붕괴된다는 메커니즘이 밝혀졌다. 연구팀은 이를 해결하기 위해 RL 탐색 단계에서만 표준 좌→우 자기회귀 순서로 dLLM을 제약하되 추론 시에는 원본 병렬 디코딩 능력을 완전히 보존하는 미니멀리스트 프레임워크 JustGRPO를 제안했다.
