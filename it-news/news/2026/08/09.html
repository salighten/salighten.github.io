NVIDIA, 에이전트를 단일 Python 클래스로 구현하는 오픈소스 프레임워크 NOOA 공개발행 2026년 08월 07일 (금)thenewstack.io

NVIDIA가 오브젝트 지향 에이전트 프레임워크 NOOA(Object-Oriented Agents)를 Apache 2.0 라이선스로 오픈소스 공개했다. 각 에이전트를 단일 Python 클래스로 구현하며, 기능은 메서드로, 상태는 필드로, 시스템 프롬프트는 독스트링에서 자동 추출한다. NOOA v0.0.8은 7월 30일 출시됐으며, NVIDIA와 36개 산업 파트너가 참여하는 'Open Secure AI Alliance' 출범과 동시에 발표됐다. 단일 클래스 설계 덕분에 에이전트의 테스트 가능성, 추적 가능성, 보안 검토가 기존 프레임워크 대비 크게 단순화됐다.

WHY IT MATTERS

NOOA의 오브젝트 지향 설계는 에이전트 코드베이스의 복잡성을 줄이고 기업 개발 팀이 기존 소프트웨어 공학 원칙(단위 테스트, 코드 리뷰)을 AI 에이전트에 직접 적용할 수 있게 한다. NVIDIA가 하드웨어 우위에서 프레임워크·생태계 주도권으로 영역을 확장하는 전략적 움직임으로, Open Secure AI Alliance는 에이전트 보안 표준화 경쟁의 새로운 축이 될 전망이다.

Hark, 브라우저 사용 에이전트 'Handoff' 공개 — Online-Mind2Web 97.7점으로 업계 최고 기록발행 2026년 08월 05일 (수)techcrunch.com

AI 스타트업 Hark(5월 시리즈A 7억 달러 유치)가 브라우저 사용 에이전트 Handoff를 공개했다. Online-Mind2Web 벤치마크에서 97.7점을 기록해 ChatGPT 5.4(92.8)와 Claude Opus 4.8(84.1)을 크게 앞섰다. Handoff는 공식 API 없이 DoorDash, LinkedIn, 항공사 예약 사이트 등 실제 상용 웹사이트에서 종단 간 작업을 완료할 수 있으며, 퍼블릭 웨이팅 리스트가 오픈됐고 8월 말 GA 예정이다. 5억 달러 이상의 벤처 자금이 브라우저 에이전트 스타트업에 집중되는 현상은 웹 기반 자동화 시장의 폭발적 성장 기대를 반영한다.

WHY IT MATTERS

브라우저 에이전트가 공식 API 없이 상용 웹사이트를 조작하는 수준에 도달한 것은 RPA(로봇 프로세스 자동화) 시장의 근본적 대체를 의미한다. 기존 UiPath, Blue Prism 등 RPA 솔루션에 의존하는 기업들은 유지보수 없는 자연어 기반 자동화로 전환 가능성을 진지하게 검토해야 할 시점이다.

MCP 역대 최대 업데이트 — 수평 확장 지원, Apps·Tasks 확장 기능 추가발행 2026년 07월 28일 (화)venturebeat.com

Model Context Protocol(MCP)이 출시 이후 최대 규모 업데이트(2026-07-28 스펙)를 발표했다. 스테이트풀 세션 핸드셰이크가 제거되어 표준 로드 밸런서 기반 수평 확장이 가능해졌다. 두 가지 공식 확장인 MCP Apps(AI 클라이언트 내 서버 렌더링 인터랙티브 UI)와 MCP Tasks(장기 비동기 작업을 위한 내구성 있는 핸들)가 함께 출시됐다. Agentic AI Foundation 산하로 이관되었으며 현재 10,000개 이상의 MCP 서버가 등록됐고 ChatGPT, Cursor, Gemini, VS Code, Copilot 등에 통합됐다.

WHY IT MATTERS

스테이트풀 세션 핸드셰이크 제거는 MCP가 개발자 실험 도구에서 엔터프라이즈 프로덕션 표준 프로토콜로 도약하는 핵심 전환점이다. 수평 확장 지원과 10,000+ 서버 생태계는 에이전트 오케스트레이션의 인터넷 인프라 역할을 MCP가 차지할 것임을 시사하며, 이를 조기 채택하는 기업들이 AI 통합 아키텍처에서 지속적 우위를 누릴 것이다.

Kimi K3: Moonshot AI의 2.8조 파라미터 오픈웨이트 멀티모달 추론 모델 완전 가이드발행 2026년 07월 16일 (목)codersera.com

중국 Moonshot AI가 2026년 7월 16일 Kimi K3를 정식 출시했다. 2.8조 파라미터 규모의 오픈웨이트 멀티모달 추론 모델로, 현재까지 공개된 오픈소스 모델 중 최대 규모다. 100만 토큰 컨텍스트 윈도우와 상시 활성화된 '씽킹 모드'를 탑재하며 입력 $3/백만 토큰·출력 $15/백만 토큰의 API를 제공한다. SWE-Bench Verified에서 76.8%를 기록해 코딩 부문 오픈 모델 최강자로 등극했으며, 전체 오픈 가중치는 7월 27일 배포됐다.

WHY IT MATTERS

Kimi K3는 클로즈드 프론티어 모델(Claude Opus 5, GPT-5.6)과 오픈 모델의 성능 격차를 좁히는 이정표다. 2.8T 규모의 오픈웨이트 공개는 자체 인프라 보유 기업들의 온프레미스 배포 가능성을 크게 높이며, 중국 AI 랩들이 오픈 모델 전략을 통해 글로벌 생태계 영향력을 확대하는 패턴이 공고해지고 있다.

ICML 2026 수상 논문 발표 — 확산 모델 두 편이 Outstanding Paper 석권, 정렬 연구에 경고장발행 2026년 07월 05일 (일)aifront-page.com

ICML 2026(7월 6~11일, 서울 COEX)에서 Outstanding Paper Award 두 편 모두 확산 모델(Diffusion Model) 연구가 차지했다. 수상작 중 하나는 '확산 언어 모델에서 임의 순서의 가치를 재고한다(The flexibility trap)'로 Zanlin Ni 외 연구팀의 논문이며, 또 한 편은 고정밀 샘플링 이론 분야다. Outstanding Position Paper는 'AI 정렬 커뮤니티가 의도치 않게 검열 도구를 만들고 있다'는 경고 논문이 수상했다. Test of Time Award는 딥마인드의 2016년 논문 A3C(비동기 심층강화학습)에 돌아갔다.

WHY IT MATTERS

2026 시계열 예측의 현주소: ARIMA에서 파운데이션 모델까지 완전 가이드aicodeinvest.com

2026년 시계열 예측 분야는 특정 작업 훈련 없이 새로운 패턴을 제로샷 예측하는 파운데이션 모델 중심으로 재편됐다. Chronos-2(프로덕션 안정성), MOIRAI-2(복잡 다변량 데이터), Lag-Llama(확률적 출력), Time-LLM(기존 LLM 인프라 활용), TimesFM(기업 신뢰성)이 각각 강점을 가진 5대 파운데이션 모델로 정리됐다.
