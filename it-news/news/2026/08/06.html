AWS Summit New York 2026: 에이전트 중심 AI 스택 혁신 대거 발표발행 2026년 07월 30일 (목)aboutamazon.com

AWS VP Swami Sivasubramanian이 뉴욕 서밋 2026 기조연설에서 에이전트 중심 AI 스택의 대규모 업그레이드를 발표했다. 핵심은 Amazon Bedrock AgentCore에 웹 검색 통합·완전 관리형 지식 베이스·Guardrails 보안 레이어를 추가해 기업용 에이전트 개발 환경을 단일 플랫폼으로 통합한 것이다. AWS는 2026년 7월 30일부로 기존 Bedrock Agents 서비스를 신규 고객에게 폐쇄하고 AgentCore를 새 표준 경로로 공식화했다. 동시 세션 기본 할당량도 미국 동부·서부 기준 최대 5,000개로 확대돼 엔터프라이즈 규모 에이전트 워크로드 지원을 강화했다.

WHY IT MATTERS

AWS가 Bedrock Agents를 단종하고 AgentCore로 통합한 것은 클라우드 벤더 주도 에이전트 플랫폼 표준화 경쟁이 본격화됐음을 의미한다. 기업 AI 담당자는 기존 Bedrock Agents 파이프라인의 AgentCore 마이그레이션 계획을 조기에 수립하고, 경쟁사(Azure AI Foundry, Google Vertex AI) 대비 AWS 스택의 거버넌스 강점을 재평가해야 할 시점이다.

Amazon Bedrock AgentCore, 광대역 지식·연속 학습 기능 추가발행 2026년 08월 01일 (토)aws.amazon.com

Amazon이 Bedrock AgentCore에 더 넓은 지식 기반과 연속 학습 기능을 추가했다고 공식 블로그에서 발표했다. Smart Parsing으로 PDF·HTML·이미지 등 멀티포맷 데이터를 자동 처리하고 Agentic Retriever로 복잡한 다단계 쿼리를 처리하는 완전 관리형 지식 베이스가 GA됐다. 보안 측면에서 Guardrails가 모든 에이전트 행동을 실시간으로 평가해 프롬프트 인젝션·유해 콘텐츠·민감 데이터 노출을 탐지한다. AWS 네트워크 밖으로 데이터가 나가지 않는 보안 웹 검색 기능도 AgentCore Gateway와 통합됐다.

WHY IT MATTERS

Guardrails 내재화와 보안 웹 검색은 금융·의료 등 엄격한 규제 환경의 기업이 에이전트를 프로덕션에 배포할 때 발생하는 보안·컴플라이언스 장벽을 낮추는 핵심 기능이다. 이 업데이트는 AWS가 단순 컴퓨팅 벤더를 넘어 '신뢰할 수 있는 에이전트 운영 환경' 제공자로 포지셔닝하려는 전략적 방향을 명확히 보여준다.
