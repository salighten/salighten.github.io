ChatGPT·Cursor·Gemini·Microsoft Copilot·VS Code 등 주요 플랫폼에 통합된 MCP 서버 수는 이미 10,000개를 돌파했다. 무상태 전환 외에도 Extensions 프레임워크 확정, 세션 핸드셰이크 제거, 보안 인증 레이어 강화가 이번 릴리즈의 3대 핵심 변경 사항이다.

WHY IT MATTERS

MCP의 무상태 전환은 기업 AI 에이전트 배포 팀에게 인프라 설계 재검토를 요구하는 중요한 기술적 분기점이다. 세션 상태 관리 로직이 사라지는 대신 보안·인증 아키텍처가 더욱 중요해지며, 이번 확정 스펙은 MCP 기반 멀티에이전트 오케스트레이션의 표준화 속도를 높여 프로덕션 도입의 최대 장벽 중 하나를 제거한다.

MCP 보안 위기 공식화: NSA 하드닝 가이드라인 발표, 실서버 10,000개 분석서 자격증명·PII 10% 이상 누출 확인발행 2026년 07월 29일 (수)theregister.com

The Register 보도에 따르면, 실제 운영 중인 MCP 서버 10,000개 이상을 분석한 결과 자격증명·API 키·개인식별정보(PII)가 10% 이상 비율로 누출되고 있음이 확인됐다. NSA는 이에 대응해 공식 MCP 하드닝 가이드라인을 발표했으며, Amazon Q에서도 도구 설명에 숨겨진 자동 실행 취약점이 발견됐다. 보안 연구자들은 MCP 도구 설명(tool description)에 삽입된 프롬프트 인젝션 공격 가능성을 추가로 경고했다. 이번 보안 이슈는 MCP 엔터프라이즈 도입 확산 시점에 맞물려 업계 전반의 보안 아키텍처 재검토를 촉발하고 있다.

WHY IT MATTERS

MCP 프로토콜이 기업 에이전트 인프라의 사실상 표준으로 자리잡으면서 보안 취약점이 구조적 위험으로 부상했다. AI 에이전트 도입팀은 MCP 서버 배포 시 자격증명 스코핑, 감사 로그, 프롬프트 인젝션 방어 레이어를 표준 설계 요소로 내재화해야 하며, NSA 가이드라인 준수 여부가 규제 산업의 에이전트 도입 승인 조건으로 부상할 전망이다.
